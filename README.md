# ⚡ Gestor de Energía con Temporizador (Windows)

"Esto está hecho para programar el apagado del ordenador desde la cama con el ratón cuando quieras, básicamente. Es puro IA slop pero me va que flipas, no me tengo que levantar. No cerréis la app
cuando le déis a iniciar, dejadla en segundo plano minimizada, no consume nada. Y ahora la morralla:

Una pequeña aplicación de escritorio ligera desarrollada en Python con **Tkinter** para programar el apagado, suspensión o hibernación de Windows de forma rápida e intuitiva.

## ¿Por qué existe este proyecto?
Este script forma parte de una colección de herramientas creadas mediante **AI-assisted coding (vibecoding)** para resolver necesidades cotidianas reales en el sistema operativo, sirviendo a su vez como un excelente método práctico para aprender programación y diseño de interfaces de usuario en Python.

## Características
* **Interfaz limpia y moderna:** Campos numéricos con formato de dos dígitos y soporte para ajustar el tiempo con la **rueda del ratón**.
* **Acceso rápido:** Botones preconfigurados de 1, 2 y 3 horas con un solo clic.
* **Multiopción energética:** Permite elegir entre **Apagar**, **Suspender** o **Hibernar** el equipo de forma segura.
* **Control total:** Temporizador en cuenta regresiva visible y botón de **Cancelar** inmediato.

## Tecnologías utilizadas
* **Python** (Lenguaje principal)
* **Tkinter** (Interfaz gráfica de usuario nativa)
* **Subprocess / PowerShell** (Ejecución de comandos del sistema operativo Windows)
